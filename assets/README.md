# DevDock 应用图标

`AppIcon.png` 为内置 imagegen 工具生成的透明背景原图；打包脚本生成 16–1024 像素的多尺寸 ICNS。无需图像处理依赖。

生成提示词：

> Use case: logo-brand. Create a finished macOS application icon for DevDock, a native developer project launcher. Single 1024x1024 icon asset, not a mockup or presentation. Centered rounded-square indigo-purple macOS tile with softly beveled edges, subtle premium dimensional lighting. Inside, a bold ivory-white terminal chevron and underscore (>_) floating above a simple small docking tray, expressing launching developer projects. Clean iconic geometry, excellent legibility at 32 pixels, generous spacing, front view, restrained depth. Match existing app purple accent. Transparent background outside the rounded-square tile, tile occupies about 86% of canvas. No words, no letters, no extra decorations, no watermark. Actual alpha transparency, not a checkerboard pattern.
